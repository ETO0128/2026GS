# 问题 4-3 安全上层策略首轮结果

上层使用拟合 Q 近似选择 EVSI 调整阈值 0、100、300 或 600 元，下层始终调用问题三滚动
LP。训练使用 2--6 月，9--12 月冻结测试，不直接输出充放电功率。

测试集固定阈值费用分别为 6,159,389.41、6,158,852.15、6,157,677.44 和
6,167,538.70 元；最优固定阈值为 300 元。学习策略选择了 0 元，费用为 6,159,389.41 元，
比最优固定阈值高 1,711.97 元。该差距虽只有约 0.028%，仍说明现有一年数据和状态特征
不足以支持 RL 替代固定规则。正式方案保留滚动 LP，学习层作为探索性消融。
